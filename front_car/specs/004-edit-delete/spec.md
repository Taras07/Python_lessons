# Ітерація 004: Редагування і видалення автомобіля

## Мета ітерації

Дозволити редагувати й видаляти вже створені автомобілі, повторно використовуючи форму з ітерації 003.

## Що вже є

Список автомобілів, фільтри, пагінація і форма створення автомобіля (ітерації 001–003).

## Що додаємо

- Кнопку «Редагувати» для кожного автомобіля: відкриває ту саму модальну форму з ітерації 003, попередньо заповнену поточними значеннями автомобіля.
- У формі редагування доступні поля: `brand_model`, `manufacturer`, `vin`, `body_type`, `engine_volume`, `horsepower`, `fuel`, `price`, `rating`, `is_available`, `description`, `year`, `options`.
- Поле `is_available` відображається як select із варіантами «Доступний» і «Недоступний».
- Збереження форми в режимі редагування виконує `PATCH /cars/{id}` замість `POST /cars/`.
- Кнопку «Видалити» для кожного автомобіля: запитує підтвердження через `confirm()` і після згоди виконує `DELETE /cars/{id}`.
- Після успішного видалення автомобіль прибирається зі списку без перезавантаження сторінки.
- Після успішного редагування оновлені дані відображаються у списку без перезавантаження сторінки.

## Явно поза межами цієї ітерації

- Детальна обробка помилок API, зокрема `404 Not Found` і `409 Conflict`, з повноцінними повідомленнями для користувача переноситься на ітерацію 005. Поки достатньо стандартного `alert()` або виводу помилки в консоль.
- Додаткові функції пошуку та сортування автомобілів не додавати.
- Не змінювати структуру бекенду, якщо наявних API-ендпоїнтів достатньо для реалізації функціональності.

## Критерії приймання

- [ ] Кнопка «Редагувати» відкриває форму з уже заповненими даними вибраного автомобіля.
- [ ] Збереження редагування надсилає `PATCH /cars/{id}` і оновлює саме цей автомобіль у списку.
- [ ] Поле `is_available` дозволяє змінити доступність автомобіля.
- [ ] Кнопка «Видалити» запитує підтвердження перед видаленням.
- [ ] Якщо користувач скасовує підтвердження, автомобіль залишається у списку.
- [ ] Після успішного видалення автомобіль зникає зі списку без перезавантаження сторінки.
- [ ] У разі помилки API застосунок не падає, а повідомляє про помилку.
- [ ] Після редагування або видалення продовжують працювати фільтри та пагінація.
